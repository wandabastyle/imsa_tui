# web-shared

Shared types for web and TUI frontends.

This crate provides common data structures and types used by both the web frontend and terminal user interface (TUI) of the IMSA timing application.

## Features

- Serializable types for cross-platform data sharing
- TypeScript bindings generation for web frontend compatibility

## Usage

This crate is intended to be used as a workspace dependency within the imsa_tui project.
